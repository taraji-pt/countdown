# Countdown — Every Second Counts\n\nPWA com relógio retro flip-flap para iPhone e GitHub Pages.\n\n- Destino: **31 de maio de 2027 às 00:00**, hora local do dispositivo.\n- Dias, horas, minutos e segundos em actualização contínua.\n- Instalar no iPhone: abrir no Safari → Partilhar → Adicionar ao ecrã principal.\n- Funciona offline depois da primeira visita.\n\nO site é servido a partir da raiz da branch `main`.\n
